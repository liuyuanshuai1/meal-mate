# frontend-my

目标：把我的页改造成用户信息和生活记录入口，弱化商城账户属性。

## 最小任务

- [ ] 修改 `pages/my/index.json`，标题为“我的”
- [ ] 保留或替换默认头像/昵称展示
- [ ] 昵称默认显示“一起吃饭叭”
- [ ] 移除或隐藏余额、充值、提现、积分、优惠券、付款订单等入口
- [ ] 增加“一起吃过”入口
- [ ] 点击“一起吃过”跳转 `/pages/eat-records/index`
- [ ] 增加“偏好设置”入口，第一版点击 toast “后续开放”
- [ ] 增加“不想吃清单”入口，第一版点击 toast “后续开放”
- [ ] 增加“关于我们”入口，点击展示简单弹窗
- [ ] 页面文案避免“订单、付款、余额、下单”等强电商语义
- [ ] 若保留记录预览，只展示最近一起吃过记录，不展示待付款状态

## 验收

- [ ] 我的页主要入口为“一起吃过”
- [ ] 用户不会从我的页进入支付、余额、优惠券、配送相关页面
- [ ] 固定 `user_id` 不直接展示给用户
